# Rune Factory 4 Special: обработка машинного перевода

В этой ветке (`rf4-special`) идёт работа над русским текстом Rune Factory 4 Special (Switch/PC).

## Что лежит в `special/machine/`

Исходный машинный перевод в том виде, в каком он был получен:

- `*.eng`: игровые файлы из `Bundle` (формат `TEXT`, как на 3DS);
- `rf3TxtMenuCommon_split1_1.eng.txt`: только текст, файла `.eng` для него не было.

Отличия формата от 3DS:
- в Special пустые записи имеют смещение 0 (длина 0), но байт NUL в теле файла для них всё равно есть;
- в диалогах (`rf3mc.eng`) 113 348 записей против 99 572 на 3DS.

## Конвертер `tools/rf4s_txt.py`

Работает так же, как RF4STextExtractor: одна строка `.txt` на запись, перенос строки внутри записи обозначается `{LF}`.

```
python3 tools/rf4s_txt.py export file.eng                  # -> file.eng.txt
python3 tools/rf4s_txt.py import original.eng file.txt out.eng
```

Проверено: все файлы из `special/machine/` пересобираются байт в байт.

## Сборка русского текста Special

Скрипт `special/tools/build_special.py` собирает все 25 текстовых файлов Special в `special/Bundle/`.
Рядом, в `special/tables/`, он кладёт таблицы для проверки: английский текст Special, русский текст и источник каждой строки.

Откуда берётся текст каждой строки (по приоритету):

1. **3DS:** наш ручной перевод. Строки Special сопоставляются с английским текстом 3DS с учётом их порядка,
   поэтому в одинаковых по-английски строках сохраняется перевод из нужной сцены.
   Если в Special изменились только переносы, перевод переносится заново под ширину окна Special (около 60 символов).
   Обрамление `''…''` и знак `＊` из Special сохраняются.
2. **Правка:** ручной перевод из `special/tr/<файл>.tsv` (`номер<TAB>перевод`).
3. **Машинный:** машинный перевод, в котором имена приведены к нашему виду по `special/glossary.json`
   (Кил, Дайлас, Даг, Эмбер, Мег, Пай, Сельфия, Серчерезо и т. д.).
4. **Англ.:** английский оригинал, если перевода нет.

```
python3 special/tools/build_special.py <папка с английскими .eng Special> <папка с английскими .eng 3DS из text/>
```
