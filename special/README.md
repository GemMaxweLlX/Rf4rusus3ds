# Rune Factory 4 Special: обработка машинного перевода

## Авторы и использованные материалы

**MonkaKarlo** (автор русского перевода RF4 Special) разрешила использовать свои файлы.
Она передала свои исходники: 19 файлов `.eng` и их версии `.txt`. Они лежат без изменений в `special/monkakarlo/`:

`rf3TxtCalendar_split2_2`, `rf3TxtCropName`, `rf3TxtFriendMonsterName`, `rf3TxtItem_split2_1`, `rf3TxtItem_split2_2`,
`rf3TxtLoad`, `rf3TxtMapName`, `rf3TxtMenuCommon_split1_1`, `rf3TxtNpc_split2_1`, `rf3TxtNpc_split2_2`,
`rf3TxtSkill_split2_1`, `rf3TxtSkill_split2_2`, `rf3TxtTouchPocket`, `rf3TxtTravelerTitleM`, `rf3TxtTravelerTitleW`,
`rf4TxtItemParameter_split2_2`, `rf4TxtQuestRequestDetailFormat_split2_2`, `rf4TxtShinkonHelp`, `rf4TxtShop_split2_2`.

Что из них вошло в готовый перевод:
- **`rf4TxtShinkonHelp`**: 182 строки подсказок к эпизодам молодожёнов. Это весь переведённый текст файла,
  остальные 178 строк — внутренние заглушки игры `RF4TXT_SHINKONHELP_*`;
- **`rf3TxtTouchPocket`**: 4 строки «Надеть» со значками кнопок Switch/ПК;
- в обеих частях имена и термины приведены к общему глоссарию, исправлены мелкие опечатки (список правок — в `MKSUB` и `MKFIX` в `special/tools/build_special.py`).

Остальные её файлы в готовом переводе не используются: эти строки взяты из нашего перевода 3DS.

**Машинный перевод** из архива `Rune_Factory_4_Special_Russian_Translation` (`special/machine/`) был отправной точкой.
В готовых файлах от него ничего не осталось, кроме ~100 служебных строк без текста (коды анимаций, номера, время).

Всё остальное — наш перевод 3DS и новый перевод строк Special (`special/tr/`).

В этой ветке (`rf4-special`) идёт работа над русским текстом Rune Factory 4 Special (Switch/PC).

## Что лежит в `special/machine/`

Исходный машинный перевод в том виде, в каком он был получен:

- `*.eng`: игровые файлы из `Bundle` (формат `TEXT`, как на 3DS);
- `rf3TxtMenuCommon_split1_1.eng.txt`: только текст, файла `.eng` для него не было.

Отличия формата от 3DS:
- в Special пустые записи имеют смещение 0 (длина 0), но байт NUL в теле файла для них всё равно есть;
- в диалогах (`rf3mc.eng`) 113 348 записей против 99 572 на 3DS.

## Конвертер `tools/rf4s_txt.py`

Работает так же, как RF4STextExtractor: одна строка `.txt` на запись, перенос строки внутри записи обозначается `{LF}`.

```
python3 tools/rf4s_txt.py export file.eng                  # -> file.eng.txt
python3 tools/rf4s_txt.py import original.eng file.txt out.eng
```

Проверено: все файлы из `special/machine/` пересобираются байт в байт.

## Сборка русского текста Special

Скрипт `special/tools/build_special.py` собирает все 25 текстовых файлов Special в `special/Bundle/`.
Рядом, в `special/tables/`, он кладёт таблицы для проверки: английский текст Special, русский текст и источник каждой строки.

Откуда берётся текст каждой строки (по приоритету):

1. **3DS:** наш ручной перевод. Строки Special сопоставляются с английским текстом 3DS с учётом их порядка,
   поэтому в одинаковых по-английски строках сохраняется перевод из нужной сцены.
   Если в Special изменились только переносы, перевод переносится заново под ширину окна Special (около 60 символов).
   Обрамление `''…''` и знак `＊` из Special сохраняются.
2. **Правка:** ручной перевод из `special/tr/<файл>.tsv` (`номер<TAB>перевод`).
3. **MonkaKarlo:** перевод MonkaKarlo (автор русского перевода RF4 Special) из `special/monkakarlo/`.
   Берётся для строк, которых нет в 3DS и которые мы ещё не перевели сами (например, подсказки эпизодов молодожёнов `rf4TxtShinkonHelp`).
   Имена приводятся к общему глоссарию, мелкие опечатки исправляются в `build_special.py`.
4. **Машинный:** машинный перевод, в котором имена приведены к нашему виду по `special/glossary.json`
   (Кил, Дайлас, Даг, Эмбер, Мег, Пай, Сельфия, Серчерезо и т. д.).
5. **Англ.:** английский оригинал, если перевода нет.

```
python3 special/tools/build_special.py <папка с английскими .eng Special> <папка с английскими .eng 3DS из text/>
```

## Состояние перевода

Готовые файлы для игры лежат в `special/Bundle/` (25 файлов `.eng`).
Для проверки рядом есть таблицы `special/tables/*.xlsx`: английский текст Special, русский текст и источник каждой строки.

Диалоги (`rf3mc.eng`, 113 348 строк):
- **около 101 500 строк** взяты из ручного перевода 3DS;
- **около 11 700 строк** нового текста Special переведены заново: эпизоды молодожёнов всех 12 супругов,
  семейные истории, новое вступление, реакции горожан на свадьбу, сообщения о сложности и прохождении,
  отладочные меню. Перевод лежит в `special/tr/part*.tsv`, список исходных строк — в `special/tr/src.json`;
- оставшиеся ~100 строк — служебные коды без текста (`M_JUMP`, `BLANK: ROW`, номера и время), их переводить не нужно.

Подсказки эпизодов молодожёнов (`rf4TxtShinkonHelp`) взяты из перевода **MonkaKarlo**.
Строки `RF4TXT_SHINKONHELP_*` — это внутренние заглушки игры, они остаются как есть.

Пол героя в новых строках задаётся меткой `＠‡сделал,сделала＠`, как в 3DS.
В эпизодах молодожёнов пол известен по супругу, там формы написаны сразу.

Сборка проверяет каждую строку: служебные метки `＠…＠`, выделение `＋`, подстановки `%`, значки кнопок и формат меток пола
должны совпадать с английским оригиналом. Сейчас ошибок нет.
