# Русский перевод текстов Rune Factory

В репозитории лежит русский перевод игровых текстов Rune Factory (диалоги, описания предметов, меню, задания, навыки).
Исходные таблицы были на английском. Перевод записан во вторую колонку каждой таблицы.

## Как устроены файлы

Каждый файл — это таблица Excel (`.xlsx`):

- **колонка A** — исходный текст (как в оригинальном файле);
- **колонка B** — русский перевод.

Если строка в колонке A уже была на русском или не является текстом (цифры, служебные символы вроде `＠`),
она скопирована в колонку B без изменений.

## Готовый игровой файл `rf3mc.eng`

В корне лежит уже собранный русский `rf3mc.eng` (кодировка UTF-8). Его можно сразу подкладывать в игру вместо оригинала,
импортировать через RuneTranslator не нужно. Собран скриптом `tools/make_eng.py` в том же формате, что сохраняет RuneTranslator.

## Импорт через RuneTranslator

Если хотите импортировать таблицу сами:

1. Закройте таблицу в Excel (программа не откроет занятый файл).
2. Откройте в RuneTranslator файл `rf3mc.eng`. Имя важно: программа ищет в таблице лист с таким же именем без расширения (`rf3mc`).
3. **Encoding → UTF-8** (кириллица в Shift JIS сохранится неправильно).
4. **File → Import Spreadsheet**, выберите `rf3mc.eng.rus.xlsx`, **Column letter = B**, **Row index = 2**, нажмите **Import**.
5. **File → Save**.

## Что сохранено при переводе

- **Служебные метки** не тронуты: `＠しゅじんこうくん＠` (имя героя), `＠アイテム０＠` (предмет), `＠キャラ０＠` и т. п.,
  выделение `＋…＋`, а также подстановки `%s`, `%d`, `%+d` и знак `%`.
  Скрипт сборки сверяет их с оригиналом в каждой строке.
- **Переносы строк** подобраны под ширину оригинала, чтобы текст помещался в окна игры.
  В шаблонах с подстановками переносы и пробелы оставлены ровно как в оригинале.
- **Пол героя:** где пол неизвестен, используются формы вида «сделал(а)».
  В сценах романов и свадеб пол героя определяется партнёром.

## Рабочие папки

Папки `translation*` нужны только для пересборки, игре они не нужны:

- `translation/` — основной файл `rf3mc`: исходник, скрипт сборки и части перевода (`tr/part*.tsv`);
- `translation_item/`, `translation_batch2/`, `translation_batch3/` — то же для остальных файлов.

Части перевода — это текстовые файлы в формате `номер<TAB>перевод`, по одной строке на уникальную английскую фразу.
Скрипт `build.py` собирает из них готовые `.xlsx`, переносит строки и проверяет служебные метки.

Мелкую правку проще всего сделать прямо в колонке B готового `.xlsx`.
